# ElevenLabs lines for the two ads

How to use: in ElevenLabs open **Text to Speech**, pick a voice, paste ONE line, generate, download the MP3.
Name each file with the id in front (for example `huss-town.mp3`) and send them to me.

Two voices per ad:
- **S** = the student: tired, deadpan, a little funny. Pick a casual young voice.
- **L** = Ledger the book: warm, upbeat, friendly. Pick a different voice from S so they don't sound alike.

Tips
- Keep the same voice for all S lines and the same voice for all L lines.
- Make a few takes of each line and keep the best one.
- Say FAR like the word "far". Say "C P A" letter by letter.
- Give the model pauses with "..." where the lines have them.

## "Huss" pronunciation (rhymes with "push", the oo sound in "put")
Try these in order and keep the first one that sounds right:
1. `Huss.`
2. `Hus.`
3. `Hhuss.`
4. If the model supports phoneme tags: `<phoneme alphabet="ipa" ph="hʊs">Huss</phoneme>`
